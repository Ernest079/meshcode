# Static comparison — real assets

Generated by `pnpm bench:static --set real` (2026-11-23). Headless Chrome, renderer: `ANGLE (Google, Vulkan 1.3.0 (SwiftShader Device (Subzero) (0x0000C0DE)), SwiftShader driver)`.
Real study (phase 4.2): only the props change (crate, barrel, drone: CC0 art by Kay Lousberg and Kenney); arena, bolt, effects and layout are code in all.
**real-glb** = the original files (GLB + meshopt; `png` atlas as shipped, `png128` atlas downsampled to ≤ 128 px, or `uastc`); **real-decompiled** = meshcode decompile's modules (geometry
as data in JS) + the original atlas PNGs; **real-code** = hand-written parametric imitations, no textures. Column "models" = whatever delivers the props.
